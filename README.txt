DANCE STUDIO — Django проект, вариант 22 «Школа танцев»
========================================================

Что внутри:
- Django + SQLite + HTML/CSS + JavaScript
- 15 сущностей предметной области (пользователь, ученик, преподаватель,
  направление, уровень, подготовка ученика, группа, зал, расписание,
  занятие, абонемент, запись, посещение, членство в группе, уведомление)
- роли: ученик, преподаватель, администратор
- каталог и фильтры расписания
- проверка направления, уровня, срока и остатка абонемента
- запрет повторной записи на одно занятие
- отметка посещаемости преподавателем
- месячная статистика и CSV
- административная панель Django

ЗАПУСК WINDOWS (Visual Studio Code)
-----------------------------------
1. Установи Python 3.11 или новее с python.org. При установке отметь
   "Add Python to PATH".
2. Распакуй архив и открой папку dance_studio_django в VS Code.
3. Открой Terminal -> New Terminal.
4. Выполни команды по очереди:

   py -m venv .venv
   .venv\Scripts\activate
   py -m pip install -r requirements.txt
   py manage.py makemigrations studio
   py manage.py migrate
   py manage.py seed_demo
   py manage.py runserver

5. Открой в браузере http://127.0.0.1:8000/

Если команда py не найдена, попробуй заменить py на python.
Если PowerShell запрещает активацию окружения, используй CMD в VS Code
или запусти .venv\Scripts\activate.bat.

ВАЖНО
-----
- База SQLite создаётся автоматически в файле db.sqlite3.
- Демо-данные создаются командой seed_demo: минимум 30 занятий и 12 тестовых записей.
- Почтовые уведомления выводятся в терминал (Django console email backend).
- Фото преподавателя загружается через Django Admin; Pillow включён в requirements.
- Карты/соцсети/контактная форма — демонстрационные элементы, не подключены
  к внешним сервисам.
- Для одновременной конкурирующей записи на последнее место SQLite имеет
  ограничения блокировок; в документе задания это ограничение также отмечено.
  Для производственной нагрузки следует перейти на PostgreSQL и добавить
  серверное ограничение/транзакционную стратегию.
- Перед публикацией в интернете нужно установить свой SECRET_KEY, выключить
  DEBUG и настроить ALLOWED_HOSTS, HTTPS, почту и резервное копирование.

Формула посещаемости:
P = фактические посещения / (активные участники × проведённые занятия) × 100%.
Если знаменатель равен нулю, показывается «Нет данных».


ОБНОВЛЕНИЕ ДИЗАЙНА:
Главная страница дополнена разделами о школе, преимуществах, направлениях,
команде преподавателей и фотогалереей. Страница преподавателей показывает
демонстрационные профили. Фотографии в оформлении загружаются с Unsplash,
поэтому для них требуется интернет. Это демонстрационные изображения, не
портреты реальных сотрудников.

ПЕРВЫЙ ЗАПУСК:
Из папки с manage.py выполните:
  py -m pip install -r requirements.txt
  py manage.py makemigrations studio
  py manage.py migrate
  py manage.py seed_demo
  py manage.py runserver

makemigrations нужен, потому что в исходном архиве не было файла начальной
миграции приложения studio. При обычном повторном запуске эти команды
повторять не нужно: достаточно активировать .venv и запустить runserver.



ФОТОГРАФИИ — КАК ЗАМЕНЯТЬ САМОСТОЯТЕЛЬНО
----------------------------------------
Главная фотография:
  static/studio/images/main.jpg

Фотографии направлений:
  ballet.jpg         — Балет
  hiphop.jpg         — Хип-хоп
  contemporary.jpg   — Контемпорари
  highheels.jpg      — High Heels
  dancefitness.jpg   — Dance Fitness
  studio.jpg         — интерьер/зал школы

Чтобы заменить фото, сохрани новое изображение в папку images и назови его
точно так же, как старый файл (например, main.jpg). Подтверди замену файла,
затем обнови сайт сочетанием Ctrl+F5. Код менять не нужно.

Фотографии преподавателей:
  Открой /admin/ → Teachers → выбери преподавателя → поле Photo.
  Загрузи новое фото и нажми «Сохранить». На сайте фото обновится автоматически.

Важно: перед заменой сохрани копию старой фотографии. Для локальных фото
предпочтительны JPG/JPEG или PNG. Для корректной загрузки фотографий
преподавателей установлен Pillow из requirements.txt.
